# 🛡️ XPTool — Real-Time Mobile Cyber Firewall

An enterprise-grade Android security suite built with Kotlin & Jetpack Compose to detect and neutralize real-time phishing, smishing, malicious QR codes, and social engineering attacks.

## ⚡ Core Shields
- **Universal App Guard:** Real-time background notification scanner for WhatsApp, WhatsApp Business, Telegram, and Instagram.
- **Message Shield:** Heuristic scam & urgency analyzer with non-blocking floating system overlays.
- **Link & Web Shield:** 5-hop redirect unmasker, homoglyph/punycode detector, and sandboxed WebView.
- **QR & Number Shield:** Instant UPI/URL QR inspection and caller reputation screening.
- **Threat Intel:** Persistent local telemetry & custom domain Blacklist/Whitelist firewall.
